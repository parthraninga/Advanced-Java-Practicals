Hello! This is a sample text file for UDP file transfer.

UDP (User Datagram Protocol) is different from TCP:
- It's connectionless (no handshake needed)
- It's faster but less reliable
- Data is sent in small packets called datagrams
- Perfect for applications where speed matters more than perfect delivery

This file will be broken into small 1KB packets and sent to the server.
Each packet travels independently through the network.
